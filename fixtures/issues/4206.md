Bug in `src/export/csv.ts`: when two transactions have the same date, amount and
description but different currencies (one EUR, one USD), only one of them shows
up in the exported CSV. I think the CSV writer is merging them. We only noticed
after 3.2.0, when transactions started carrying a currency.
